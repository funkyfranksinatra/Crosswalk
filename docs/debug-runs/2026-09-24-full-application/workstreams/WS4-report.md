## 5. Authorization matrix summary (`EV/authz-matrix.csv`, 1,638 rows, 0 × 5xx, 0 throws)

- **Anonymous** (133 calls): 401 on every gated handler (123); the 10 handlers without `handle()/authorize()` answer for themselves — `GET/DELETE /api/auth/dev` 200 (dev mode), `POST /api/auth/dev` 400 (unknown user), `GET /api/auth/me` 200 `{actor:null}`, the three OIDC routes 404 (SSO unconfigured), `GET /api/health` 200, `GET /api/metrics` 401, `POST /api/webhooks/salesforce` 404 (integration disabled; 401 for a bad signature when enabled).
- **Roles** (11 × 132, 19 authorized side-effecting calls skipped by design — enrich/publish/analytics-refresh/system/feeds POSTs): every "permission missing" call is 403; every authorized call is a 200/400/404/409 (400 = validation on an empty body, 404 = the well-formed unknown id), never 401/403/5xx. `GET /api/metrics` and `GET /api/observability/export` refuse every role but ADMIN (401 / 403 respectively, by design).
- **Owner vs stranger** on all 29 `/api/(accounts|requests|proposals|contracts)/[id]**` routes (35 method pairs): the stranger rep gets 404 on the 30 pairs whose permission a rep holds and 403 on the 5 that need `manage_contracts`/`edit_contract_pricing` (memberships POST, contract PATCH, entries POST, terms POST/DELETE) — the same 403 for an unknown id, so no existence leak; the owner gets 200 on every read (the one 400 is the quote export, locked by the fixture's pending approval, exercised separately in the redaction suite).
- `handle(null)` handlers, each justified: `GET /api/notifications`, `POST /api/notifications`, `GET/PATCH /api/notifications/preferences` (the caller's own rows only); `GET /api/settings` (weights, model name/baseURL flag, call stats — no secrets; the write is `configure_settings`); `GET /api/google` (Drive configured-ness); `GET /api/catalog/gudid` (library counts) and `GET /api/catalog/gudid/[id]` (import job status: query text, counts, starter's name — acceptable for any staff role, recommend `manage_catalog` if the job log ever carries more); `GET /api/observability/export` (ADMIN check inside, 403 for everyone else); `POST /api/integrations/review/[id]` (per-item permission resolved from the item's integration key inside the handler).
